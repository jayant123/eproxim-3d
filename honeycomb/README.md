# honeycomb

Homepage hero for eproxim.com: a three.js honeycomb that builds in around the hero copy, with flying honeybees.
Each time the headline names a new system, a bee fills one cell in the row under the buttons. A second bee
flies in and hovers at the right of the window once the hero scrolls away.

- `honeycomb.js` - bundled module (three@0.160.1 inside), built from eproxim-seo `pages/home-honeycomb`.
- `widget-v1.0.0.html` - the snippet for the hero's HTML widget (replaces the portraits snippet).
